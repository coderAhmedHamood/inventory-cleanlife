# نظام إدارة المخازن (Inventory Management System)

نظام متكامل لإدارة المخازن والمخزون مبني باستخدام Next.js و Tailwind CSS.

## المميزات الرئيسية

### 1. الإعدادات (Configuration)
- **المستودعات**: إدارة المستودعات والمواقع التخزينية
- **المواقع**: مواقع داخلية، موردين، عملاء، جرد، إنتاج، هالك
- **المنتجات**: إدارة المنتجات مع أنواع مختلفة (قابل للتخزين، استهلاكي، خدمة)
- **الفئات**: تصنيف المنتجات مع طرق التقييم والتكلفة (FIFO, AVCO, Standard)
- **وحدات القياس**: إدارة وحدات القياس والتحويلات
- **أنواع العمليات**: استلام، صرف، تحويل، جرد، هالك
- **الشركاء**: موردين وعملاء

### 2. العمليات (Operations)
- **الإيصالات**: إدارة إيصالات الاستلام من الموردين
- **التوصيل**: إدارة أوامر التوصيل للعملاء
- **التحويلات**: نقل المخزون بين المواقع
- **التسويات**: تعديل المخزون
- **الهالك**: إدارة المنتجات التالفة

### 3. التقارير (Reports)
- **تقرير المخزون**: عرض المخزون الحالي مع إمكانيات التصفية
- **سجلات الحركة**: عرض جميع الحركات المخزنية
- **تحليل الحركة**: تحليل وتتبع حركات المخزون

### 4. لوحة التحكم
- إحصائيات شاملة
- آخر الحركات
- تنبيهات المخزون المنخفض

## التقنيات المستخدمة

- **Next.js 14**: إطار عمل React مع App Router
- **TypeScript**: للكتابة الآمنة
- **Tailwind CSS**: للتصميم والتنسيق
- **Zustand**: لإدارة الحالة
- **Lucide React**: للأيقونات

## التثبيت والتشغيل

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل المشروع في وضع التطوير:
```bash
npm run dev
```

3. فتح المتصفح على:
```
http://localhost:3000
```

## البنية الهيكلية للمشروع

```
inventory-system/
├── app/                    # صفحات Next.js
│   ├── dashboard/          # لوحة التحكم
│   ├── configuration/      # صفحات الإعدادات
│   ├── operations/         # صفحات العمليات
│   ├── products/           # صفحة المنتجات
│   └── reports/            # صفحات التقارير
├── components/             # المكونات المشتركة
│   └── Layout.tsx          # تخطيط الموقع
├── store/                  # إدارة الحالة
│   └── useStore.ts         # Zustand store مع البيانات
└── package.json
```
